# Автономные проверки

Тесты используют стандартный `unittest`, временные каталоги и подмену внешних вызовов. Они не требуют входа в Profi.ru, реального браузерного профиля или настоящего токена Telegram.

Проверяются:

- Парсер: нужная структура, вложенные ответы, пакетные ответы, пустые списки и некорректные ID.
- Конфигурация: значения по умолчанию, допустимые интервалы и отсутствие токена в `repr`.
- Состояние: сохранение, повреждённые файлы, атомарная запись и очистка временного файла.
- Монитор: подтверждённая доставка, неуспешная отправка, частичный успех групп и повтор обработки.
- Уведомления: сортировка, длина сообщений и сохранение всех ID при разбиении.
- Адаптеры: фильтрация ответов браузера, выбор адресата и безопасное логирование ошибок Telegram.

Команда проверки: `python -m unittest discover -s tests -v` при доступном Python-пакете. Контрактные проверки подменяют HTTP и Playwright-ответы; сквозной запуск настоящих сервисов сюда не входит.
