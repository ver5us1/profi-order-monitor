# Вспомогательные скрипты

| Файл | Назначение |
| --- | --- |
| [RUNNER.command](RUNNER.command) | Launcher для macOS: открывает два окна Terminal, отдельно для сборщика и монитора |
| [setup.sh](setup.sh) | Подготовка локального `.venv`, Python-пакета и Chromium для Playwright |

Скрипты рассчитаны на корень нового репозитория и локальное окружение `.venv`. Launcher использует корректное quoting путей с пробелами. Подробная инструкция по настройке будет добавлена после проверки полного сценария.

В текущей проверке выполнен только контроль shell-синтаксиса; нативный запуск Terminal через AppleScript на macOS не проверялся.
