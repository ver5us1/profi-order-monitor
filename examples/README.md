# Демонстрационные данные

Все идентификаторы в этой папке вымышлены. Снимки содержат только минимальную структуру, которую использует парсер, а не полный ответ личного кабинета.

| Файл | Содержание |
| --- | --- |
| [board-before.json](board-before.json) | Два уже известных ID: `demo-order-001` и `demo-order-002` |
| [board-after.json](board-after.json) | Те же ID и два новых: `demo-order-003`, `demo-order-004` |
| [state.example.json](state.example.json) | Образец структуры истории известных ID |
| [demo.py](demo.py) | Сравнение двух снимков и вывод текста уведомления |

`demo.py` не открывает браузер, не читает `.env`, не отправляет сообщение и не меняет рабочее состояние. Его назначение — показать результат сравнения без внешних сервисов.
