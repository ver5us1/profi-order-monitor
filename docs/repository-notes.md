# Подготовка репозитория

Исходный проект состоял из двух основных скриптов, локального состояния и launcher для macOS. При подготовке к публикации сохранена идея «снимок → новые ID → Telegram», а технические обязанности разделены по модулям.

| Область | Изменение |
| --- | --- |
| Организация | Python-пакет в `src/`, отдельные `docs/`, `examples/`, `scripts/` и `tests/` |
| Конфигурация | Токен и параметры вынесены из исходников; добавлен `.env.example` |
| Данные | Личные ID, реальное состояние, выгрузки и браузерная сессия не включены |
| Доставка | Неуспешная отправка больше не помечает новые ID обработанными |
| Разбор | Объединяются все подходящие списки во вложенных и пакетных ответах |
| Файлы | Добавлена атомарная запись; повреждённая история не сбрасывается незаметно |
| Уведомления | Большой список делится на группы, подтверждённые группы сохраняются отдельно |
| macOS | Launcher учитывает пробелы в путях; вспомогательная подготовка использует локальное окружение |
| Проверки | Добавлены автономные тесты и workflow GitHub Actions без реальных внешних вызовов |

Проверка логики на синтетических данных не заменяет повторный запуск с реальной сессией после этих изменений.
